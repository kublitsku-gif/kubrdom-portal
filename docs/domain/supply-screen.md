# Экран закупки (снабжение)

- **Магазин — одна вывеска и при показе.** `supplyCollect` прогоняет `m.store` через `normStore` (алиасы: Ozon/ozon.ru → «Озон», Яндекс.Маркет → «Яндекс Маркет», Grand Line): иначе «Ozon» и «Озон» давали два чипа и две корзины. Данные не переписываем — правка строки через «изм.» и так сохраняет приведённое имя. Цвета — только общий `SC`, своей карты в снабжении больше нет.
- **Сбор и фильтры — общие** (`supplyCollect`, `supplyFilter`): по ним рисуется экран, собирается печатный лист (`buildSupplyList`) и текст «отправить списком» (`supplyListText`). Своя выборка в каждом означала бы, что уехало не то, что на экране. Чипы магазинов считаются по списку ДО выбора магазина (`skipStore`), с суммой и по убыванию суммы.
- **Первый экран — одна сводка** «куплено / на складе / осталось», структура затрат раскрывается тапом; деньги везде до рубля (`supplyRub`). Редкое — в меню «⋯» шапки: печатный лист и включение «оплачивает заказчик». Блок «Не покупаем — это работы» — внизу списка, пилюля «🔨 это работа» — в форме правки строки, а не в каждой строке.
- **Виды: «Закупка» (магазины), «Этапы», «Работы».** Старое «Магазины» совпадало с «Закупкой» до строки; `sortBy==="store"` ведём на «Закупку». Шапка группы липкая под шапкой приложения (`top:var(--hdr)`), поэтому у карточки группы НЕТ `overflow:hidden` — он делает её контейнером прокрутки и гасит липкость.
- **Статус строки — лента шагов** `нужно → заказано → куплено → на складе` (`supplyStepper`, `SUPPLY_STEPS`/`supplyStep` в `src/supply.js`). «Заказано» (`m.ordAt`) и «привезут» (`m.eta`) живут НА МАТЕРИАЛЕ, как `client`; срок видит мастер в приёмке. Дата пишется по `change`.
- **Фактическая цена** — `m.fact` (₽ за единицу) у купленной строки. Равную смете не храним. `needStatus` считает «потрачено» по факту; при партиях факт — это `price` позиции партии, их держим в согласии. Разница с планом (`factTotals`) — ТОЛЬКО по позициям с записанным фактом: «не записали» не значит «по смете».
- **Пачка «куплено» — сразу и с возвратом** (`supplyMarkBought`, тост `_undoToast` на 5 с, один на экран). Подтверждение не спрашиваем — его жмут не читая. Одиночная строка — без тоста: повторный тап и есть отмена, а тост на каждую галочку закрывал бы корзину. Свайп вправо — «куплено», влево — «на склад» (`bindSupplySwipe`, pointer-события, строка с `touch-action:pan-y`; действие после click через `setTimeout`, иначе перерисовка подменяет строку под пальцем).
- **Корзина магазина** — липкая панель внизу при выбранном магазине (`bottom:var(--botbar)`, высоту нижней панели меряет `syncBottomBarVar`): остаток, «📤 список», «📄 ТЗ» для офлайн-поставщиков, сайт, «✓ Куплено N».
- **Строки в группе — по работам в порядке сметы, не по алфавиту** (`_mergeMats`: ранг работы — первое её появление в списке, внутри работы — порядок материалов; `rowsByWork` ставит над блоком подпись «↳ работа · N поз.», если работ в группе больше одной). По алфавиту водорозетка и фитинги одной работы разъезжались между гвоздями и гофрой. Одноимённые работы разных объектов идут одним блоком, слитая строка — к своей первой работе.
