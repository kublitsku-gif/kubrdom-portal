# Просмотр фото и видео работы

Код: `mediaView`, `workMedia`, `mediaOpen`, `mediaStep`, `mediaViewModal` в `public/admin.js`; сторожит `test-media-view`.

- **Зачем.** «Вижу, что есть фото» и «могу их посмотреть» жили на разных экранах: значок на Ганте только уводил в карточку объекта, а видео открывалось ссылкой в Telegram. Теперь тап по 📷/🎬 открывает галерею поверх любой вкладки.
- **Просмотрщик держит АДРЕС работы (`oid/sid/wid` + индекс), а не копию файлов.** Живой опрос приносит новое фото — оно появляется в ленте само. Копия списка разъехалась бы со снимком.
- **Список один: сначала фото, потом видео.** Индекс `data-i` — позиция в этом общем списке, поэтому 🎬 открывается с `data-i = photos.length`. Список видео в карточке работы показан в ОБРАТНОМ порядке, там индекс пересчитывается (`photos.length + (vids.length-1-vi)`).
- **Видео играет прямо в портале** через `/api/tg-video/<fileId>` — публичный прокси Worker'а (роут стоит ДО авторизации, как и `/api/file/`, потому что `<video src>` заголовков не шлёт). Bot API отдаёт файлы **до 20 МБ**, поэтому рядом всегда есть «▶ Открыть в Telegram» и строчка, объясняющая, почему тяжёлый ролик не проигрался. Пустой чёрный прямоугольник без объяснения — худший исход.
- **Листание по кругу** (`mediaStep`): на телефоне так меньше тупиков, чем упираться в край. Плюс стрелки клавиатуры и Esc — слушатель на документе ставится один раз (`window._mediaKeys`).
- Значки 📷/🎬 на Ганте лежат ВНУТРИ кликабельной подписи работы, поэтому их обработчик гасит всплытие: иначе тап уводил бы в карточку объекта вместо галереи.
- Точки входа: значки на Ганте, миниатюры в блоке «ФОТО ВЫПОЛНЕНИЯ» и кнопка «▶ Смотреть» в списке видео работы.
- **На Ганте фото и видео стоят ещё и в клетке ДНЯ** (по `photo.date`/`video.date`), кнопкой `media-open` с индексом первого файла дня. Счётчика в подписи мало: бригадир закрыл работу с фото сегодня, а начальник смотрит колонку «сегодня» и там пусто.
- **✓ «выполнено» на Ганте — самый поздний из дней: последний день с часами и `doneAt`.** Раньше брался только день часов: час на «Разводку электрики» записали 14.09, закрыли с семью фото 21.09 — ✓ уехал на неделю назад (живой случай 21.09.2026).
