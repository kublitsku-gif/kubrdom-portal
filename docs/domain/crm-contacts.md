# Клиенты CRM в телефонной книге (CardDAV)

Зачем: при входящем звонке телефон показывает не голый номер, а «КД-057 📄 Светлана Орлова». Браузер/PWA входящий звонок не видит (amoCRM делает это своим нативным приложением), поэтому клиенты отдаются телефону как отдельная адресная книга по стандарту CardDAV, а имя высвечивает сама звонилка.

- **Код клиента** `c.code` (число) → `clientCode` = «КД-057». Выдаёт панель (`assignClientCodes` в конце `crmAutoLinkAvito`, т.е. при загрузке диалогов CRM): следующий после максимального, по порядку заведения (`date`, `createdAt`). Один номер у двоих (две вкладки завели клиентов одновременно) — позднему новый. Номер не переиспользуется и не меняется. Виден в шапке карточки клиента.
- **Имя контакта** — `contactName`: код, значок стадии (`STAGE_ICON`, те же, что в `CRM_STAGES` админки — при правке стадий менять в обоих местах), имя. На экране звонка ~25 символов — главное в начале. `ORG` = «КубрДом · источник · стадия», `NOTE` — первое сообщение/заметки, `URL` — ссылка на карточку `/crm?go=client%3D<id>`. В книге только клиенты с телефоном.
- **Протокол** — `src/carddav.js`, только чтение: OPTIONS, PROPFIND (`/api/dav/` → `principal/` → `books/` → `books/crm/` → `<id>.vcf`), REPORT `addressbook-multiget`/`addressbook-query`, GET (GET книги — все vCard одним файлом). PUT/DELETE → 403, привилегия только `read` — DAVx⁵ помечает книгу «только чтение». Удалённый клиент в multiget → 404, и телефон его стирает. Адреса под `/api/`, потому что наружу Worker виден только через прокси Pages `/api/*` (он пропускает любые методы).
- **Вход** — Basic: логин = телефон сотрудника (`79032599333`, принимается в любом формате, сверяются 10 последних цифр), пароль = «пароль для телефона», выданный в CRM (`POST /api/crm/contacts-token`, вид `xxxx-xxxx-xxxx-xxxx`, без 0/o/1/l/i; дефисы и регистр при входе не важны). В D1 только HMAC: строка `work_states` `dav_tokens/<uid>` (в снимок не попадает, версию не двигает). Новый пароль отменяет старый, `{revoke:true}` — отключить. Право CRM (`pushAllowUid`: admin / crm / marketing, не `disabled`) проверяется на КАЖДЫЙ запрос книги. Мастер-токену пароль не выдаётся. Маршрут `/api/crm/*` — под правом crm/marketing (`routeAllowed`).
- **Экран** — блок «📇 Клиенты в телефонной книге» во вкладке «📊 Сводка» (`crmContactsHtml`, состояние `crmDav` — экранное): статус, «Подключить телефон» / «Новый пароль» / «Отключить», адрес-логин-пароль с копированием (пароль показан один раз), инструкция для DAVx⁵ и iPhone.
