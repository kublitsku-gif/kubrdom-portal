# Нейропродавец: Avito → черновик в Telegram

- Конвейер: вебхук Avito (`avitoWebhook`) → `aiProcessIncoming` → ветка клиента в группе sales-бота → `aiSellerReply` → черновик с кнопками «✅ Отправить / ✏️ Изменить» (или автоответ, если `settings.aiAutoSend` и ответ 🟢). Отправка в Avito — `avitoSend`.
- Мозг выбирается тумблером «Модель ИИ» во вкладке Маркетинг (`settings.aiProvider`), Worker читает его в `aiProvider`, доступы — `aiResolve`. **В выборе только Claude Sonnet (по умолчанию), Claude Haiku и Kimi** (`AI_PROVIDERS` в admin.js и тот же список в `aiProvider`). DeepSeek/Yandex/GPT из выбора убраны по решению заказчика 27.10.2026; их ветки в `aiResolve` живы (Yandex нужен голосовому роботу через `voiceProvider`), но старое значение в настройках и панель, и Worker считают Sonnet.
- **Claude — `aiProvider:"claude"`, модель `CLAUDE_SELLER_MODEL` (wrangler.toml, `claude-sonnet-5-5`).** Запрос собирает `src/claude-chat.js` (`claudeBody`/`claudeText`, сторожит `test-claude-chat`). Гочи Sonnet 5.5:
  - `temperature`/`top_p`/`top_k` не слать — 400 на любое недефолтное значение;
  - `thinking:{type:"disabled"}` — 400; мышление включено всегда и ест `max_tokens` вместе с ответом, поэтому пол 4000 (500, которых хватало DeepSeek, обрезали бы реплику); глубину держит `output_config.effort:"low"`;
  - отказ по политике — `fallbacks:"default"` + `anthropic-beta: server-side-fallback-2026-07-01`; если отказала вся цепочка, `claudeText` бросает ошибку, и в ветку уходит «⚠️ Не удалось подготовить ответ ИИ» — человек отвечает сам;
  - история режется хвостом и может начаться с нашей реплики — первые assistant-сообщения отбрасываются (API ждёт первым user).
- **Claude Haiku — `aiProvider:"claudehaiku"`, `CLAUDE_HAIKU_MODEL` (`claude-haiku-5-5`)**, тот же ключ и тот же `claudeBody`, но без `fallbacks` и beta-заголовка: серверного fallback у Haiku нет.
- `CLAUDE_MODEL` (sonnet-4-6) — это распознавание планировок (`/api/plan-read`), не путать с продавцом.
- **Факты с сайта kubrdom.ru — `settings.aiSiteKnowledge`** (вкладка «🌐 Сайт» в «📋 Инструкции нейропродавца»). `aiSellerPrompt` приклеивает их после инструкции бани/дома (`withSiteKnowledge` в `src/site-knowledge.js`) с пометкой «главный источник, при расхождении верь сайту»: в инструкциях жили старые цены дома (1,4 млн), адрес «метро Битца» и подпись «Светлица», а сайт — актуален.
  - Кнопка «Собрать заново» → `POST /api/ai/site-knowledge` (только админ, платный запрос): Worker берёт страницы из `sitemap.xml` (только https того же хоста, ≤25), режет HTML в текст, Claude Sonnet (effort medium) пишет выжимку ≤9000 знаков. Ответ НЕ сохраняется — уходит в textarea, админ проверяет и жмёт «Сохранить». Страницы сайта в промпте помечены как данные, не указания.
  - Сторожит `test-site-knowledge`.
- **Голос в песочнице** — кнопка 🎤 (`mkt-test-mic` → `mktMicToggle`): диктовка браузера (Web Speech API, `ru-RU`), сервер не нужен. Сказанное дописывается в поле, само не уходит — правим и жмём ➤. Кнопку красим точечно, без перерисовки: перерисовка стёрла бы надиктованное. Нет API (Firefox, часть WebView) — алерт «откройте в Chrome или Safari». Сторожит `test-mkt-mic-ui`.
