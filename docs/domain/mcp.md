# MCP: портал для ИИ-клиентов (только чтение)

- `POST /api/mcp` (`src/mcp.js`) — Model Context Protocol поверх Streamable HTTP, без состояния. Подключается в Claude Code / Claude Desktop / коннектором claude.ai и отвечает на «что просрочено», «что докупить», «кто что менял».
- **Путь именно `/api/mcp`, не `/mcp`**: Pages-функция проксирует в Worker только `/api/*`, всё остальное на своём домене отдаёт Pages. На `/mcp` пришёл бы 404, и остался бы `*.workers.dev`, который в РФ режется по SNI.
- Секрет **`MCP_TOKEN`** отдельный от `ADMIN_TOKEN`, схема `Authorization: Bearer`. Панельный токен сюда не пускают намеренно: он даёт запись всего снимка, а это машинный эндпоинт наружу. Не задан секрет — эндпоинта нет (404, fail-closed): не «пускаем всех» и не подсказываем 401-ом, что тут что-то есть. Задаётся вручную (`wrangler secret put MCP_TOKEN`), деплои его не трогают — как `TG_BOT_TOKEN`.
- **Только чтение, и это не временно.** Снимок пишется разделами со сторожем `base`, серверной проверки прав по `work_id` у записи нет (панель — доверенный клиент). Пока её нет, писать через открытый наружу токен нельзя. Финансовые разделы (`finSalaries`/`finTxns`/`finContracts`/`finExtraWorks`) не читает НИ ОДИН тул — тест это стережёт.
- **Считаем на сервере, а не отдаём снимок.** Раздел `objects` — сотни килобайт; «какие этапы горят» из него клиент вычислял бы, затащив всё в контекст. Тулы зовут те же `src/stages.js` и `src/supply.js`, что крон и бот, и отдают десяток строк. Отсюда правило: **новый тул не тащит данные наружу, а переиспользует общий модуль** — иначе цифра в чате разойдётся с цифрой на экране (та же причина, по которой `objStats` живёт в `botview.js` и экспортируется, а не копируется).
- Ответ тула режется на 20 000 символов с подсказкой сузить запрос: сервер существует ради экономии контекста, и раздувшийся тул должен обрезаться, а не съедать окно.
- Транспорт: только POST (GET → 405). Потока SSE нет намеренно — сервер без состояния, серверных уведомлений не шлёт. Пакетные запросы не поддерживаются (спека их и убрала).
